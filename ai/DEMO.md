# DubScript Studio AI — Demo Script (2–4 minutes)

**Format:** screen recording / screenshots of the live app + Hindi voice-over.
**Goal:** problem → load subtitles → AI panel (own key) → AI fills lines →
fit badges verify → export.

---

### 0:00–0:25 — Hook / problem
**Say:** "आप donghua या anime को Hindi में dub करते हैं, तो ये दर्द आप जानते
हैं — हर line हाथ से translate करो, और recording के time पता चलता है कि line
scene में fit ही नहीं होती। Take बर्बाद।"
**Show:** title card / app header — *DubScript Studio AI by Prime Khatab Services*.

### 0:25–0:50 — Load subtitles
**Say:** "ये है DubScript Studio AI। कोई भी subtitle file दो…"
**Click:** **Load demo lines**.
**Show:** the sheet fills with 10 lines — timings, slot durations, original lines,
all badges "Not written".

### 0:50–1:20 — The AI panel (bring your own key)
**Say:** "v2 में नया है AI agent panel। यहाँ आप अपनी खुद की API key डालते हैं —
key सिर्फ आपके browser में रहती है, किसी server पर नहीं जाती। Base URL और
model भी आप अपने हिसाब से बदल सकते हैं।"
**Show:** AI panel with base URL `https://api.hilinkup.com/v1`, model
`deepseek/deepseek-v4.1-flash-1017`, and a **masked** key in the password field.

### 1:20–2:05 — AI fills all Hindi lines
**Say:** "अब एक click — AI: fill all Hindi lines। हर line के साथ उसका slot
time भी जाता है, तो AI उतनी ही लंबी Hinglish line लिखता है जितनी उस scene में
बोली जा सके — करीब 14 characters per second। Progress live दिखता है, और बीच
में stop भी कर सकते हैं।"
**Show:** progress bar (n/10), rows filling one by one, badges turning
🟢 Fits / 🟡 Tight.

### 2:05–2:40 — Fit check verifies every line
**Say:** "और सिर्फ translate नहीं — हर line का fit check भी होता है। Green
मतलब आराम से fit, yellow मतलब थोड़ा fast बोलना पड़ेगा, red मतलब line लंबी
है — recording से पहले ही पता चल जाता है। कोई line पसंद न आए तो हाथ से edit
करो, badge उसी time update हो जाता है।"
**Show:** filled sheet, stats (10 written, 0 too long), one manual edit.

### 2:40–3:10 — Export
**Say:** "Sheet तैयार? एक click में CSV download — voice artists के लिए।
और dubbed SRT — video में सीधे लगाने के लिए।"
**Click:** **Download dubbing sheet (.csv)**, **Download dubbed subtitles (.srt)**.
**Show:** export section + the exported SRT lines.

### 3:10–3:30 — Close
**Say:** "DubScript Studio AI — free, आपकी अपनी key, कोई server नहीं। Prime
Khatab Services की तरफ से, हर dubbing creator के लिए।"
**Show:** header/branding. End card: **DubScript Studio AI — by Prime Khatab Services**.

---

**Recording notes**
- The API key field is a password field — it always shows masked dots.
  Never type or show a real key on camera; use a fake one for the panel shot.
- Browser zoom 110–125% keeps the fit badges readable.
- Total spoken words ≈ 330–380 → lands at ~2.5–3.5 minutes at a natural pace.
